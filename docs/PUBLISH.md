# 공유 저장소 운영과 공개 점검

현재 저장소는 **Private** 검토 상태다. 소유자의 요청으로 정리된 코드·문서만 복사해 새 저장소를 만들며 기존 저장소의 Git 이력·remote·브랜치·태그·캡처·운영 상태는 가져오지 않는다. 기존 비공개 저장소의 이력을 삭제하거나 교체하지 않는다. 새 저장소 재공개도 별도 지시 후 진행한다.

- 개인 비서 이름과 개인 이름 기반 경로·식별자를 기본값으로 넣지 않는다. 문서의 비서는 제품 역할명으로 구분한다.
- `tools/check_public.py`, 자동 테스트, 문서 링크, 커밋 파일과 작성자 메타데이터를 검토한다. 자동 검사 통과가 개인정보 안전의 보장은 아니다.
- 실제 폴더·계정·토큰·대화·노트·로그·DB·앱 캡처는 공유 파일에 포함하지 않는다. 개인 설정은 운영 Mac의 비공개 파일에 둔다.
- 라이선스는 MIT이며 외부 서비스·의존성은 각자의 조건을 따른다.
- 새 공유 namespace는 기존 개인 운영 설치와 자동 호환된다고 가정하지 않는다. 이 공유본을 운영 Mac에 자동 덮어쓰지 않는다.

과거 공개 저장소의 다운로드·캐시·복제본은 새 저장소를 만들어도 회수되지 않는다. 새 저장소가 과거 공개의 흔적까지 제거했다고 주장하지 않는다.
