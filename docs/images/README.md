# 개인정보를 가린 화면 예시

- `photo-transfer-redacted.png`: 사용자 제공 화면에서 Telegram 사진과 Pickle 수신 사진 부분만 잘라 나란히 배치했다. 계정/비서 이름·다른 토픽·이전 대화·가족 관련 응답·프로필은 제외하고 요청문은 불투명하게 가렸다.
- `file-receipt-redacted.png`: 가상 Markdown 시연 응답의 프로필 영역을 제외하고 이름이 들어간 줄 전체를 불투명하게 가렸다.
- `attachment-menu-redacted.png`: 파일 첨부 메뉴 부분만 잘랐다. 개인 프로필·연결 주소·파일 경로를 포함하지 않는다.

각 최종 파일을 직접 열어 검토했다. 수정본은 평탄화된 PNG이며 원본·레이어·EXIF·텍스트 메타데이터를 넣지 않는다. 원본 캡처는 이 저장소에 없다. `tools/check_public.py`는 이 세 파일의 정확한 해시만 허용하며, 변경/추가 캡처와 심볼릭 링크는 자동 통과시키지 않는다. 다른 제공 화면은 실제 연결 주소·통화 정보·개인 자료가 섞여 있어 포함하지 않았다.

이미지는 실제 화면 일부를 잘라내고 가린 것이며 UI 문구나 결과를 새로 만들어 넣지 않았다. 사진 전달이나 가상 문서 수신 장면을 설치 성공·자동 게시·전화 완료의 증거로 확대하지 않는다. 제3자 UI·캐릭터의 권리는 각 권리자에게 있으며 저장소의 MIT 라이선스가 그 권리의 소유를 주장하지 않는다.
