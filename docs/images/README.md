# 개인정보를 가린 화면 예시

- `photo-transfer-redacted.png`: 원본의 왼쪽 Pickle·오른쪽 Telegram 창 전체와 배치를 유지했다. 비서 이름·다른 채팅/토픽 목록·이전 대화 미리보기·가족 관련 응답·요청문의 개인 이름을 불투명 박스로 가렸다. 원본 바깥 위쪽에 앱 구분용 영문 이름만 추가했다.
- `file-receipt-redacted.png`: 가상 Markdown 시연의 Pickle 창 전체를 유지하고 프로필 이름 및 이름이 포함된 응답 줄을 불투명하게 가렸다.
- `attachment-menu-redacted.png`: Pickle 창과 첨부 메뉴 전체를 유지하고 프로필 이름·이름이 들어간 응답 및 메뉴 밖 대화 부분을 불투명하게 가렸다.

세 최종 파일을 직접 열어 검토했다. 단순 흐림이나 레이어를 얹은 파일이 아니라 가린 영역의 픽셀을 교체해 평탄화한 RGB PNG다. 원본·레이어·EXIF·텍스트 메타데이터를 넣지 않는다. 가리지 않은 원본은 이 저장소에 없다. `tools/check_public.py`는 검토한 세 파일의 정확한 해시만 허용하며 변경/추가 캡처와 심볼릭 링크는 자동 통과시키지 않는다. 실제 연결 주소·통화 정보·개인 자료가 섞인 나머지 화면은 포함하지 않았다.

실제 UI 문구·결과를 새로 만들거나 비서 이름을 다른 이름으로 바꿔 넣지 않았다. 사진 전달과 가상 문서 수신 장면을 설치 성공·자동 게시·전화 완료의 증거로 확대하지 않는다. 제3자 UI·캐릭터의 권리는 각 권리자에게 있으며 저장소의 MIT 라이선스가 그 권리의 소유를 주장하지 않는다.
